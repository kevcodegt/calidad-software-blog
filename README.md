# La importancia de medir la Calidad del Software

Blog académico de Kevin Santizo, adaptado visualmente con los colores y el escudo de la Universidad Mariano Gálvez de Guatemala. El escudo proviene de https://www.umg.edu.gt/img/Umg.png y se incluye localmente en `images/umg.png` para que aparezca al publicar en GitHub Pages. El contenido se basa en el material académico proporcionado para la tarea. Proyecto estudiantil independiente; no es un sitio oficial de la universidad.

## Publicación en GitHub Pages

1. Descomprime el ZIP.
2. Crea un repositorio **público** llamado `calidad-software-blog`.
3. Sube `index.html`, `styles.css`, `script.js` y la carpeta `images` a la raíz del repositorio.
4. En **Settings → Pages**, elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
5. Espera a que finalice el despliegue y abre `https://TU-USUARIO.github.io/calidad-software-blog/` en una ventana de incógnito para verificar el acceso público.

La ruta del escudo es relativa, por lo que funciona también bajo el subdirectorio de GitHub Pages. El sitio es estático y no solicita credenciales.
