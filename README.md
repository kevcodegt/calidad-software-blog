## Publicar con GitHub Pages
1. Crear un repositorio público en GitHub, por ejemplo `calidad-software-blog`.
2. Subir `index.html`, `styles.css` y `script.js` a la raíz del repositorio.
3. Entrar a **Settings > Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Seleccionar `main` y `/ (root)`, luego **Save**.
6. Esperar el despliegue y abrir la URL que GitHub Pages muestre.
7. Probar el enlace en una ventana de incógnito para confirmar que no solicita usuario ni contraseña.
